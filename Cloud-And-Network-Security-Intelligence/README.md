# Cloud & Network Security Intelligence Dashboard

This project demonstrates how Splunk Enterprise can be used to monitor cloud and network security activity through a centralized security intelligence dashboard.
The dashboard combines authentication logs, network activity, and cloud-related information to provide visibility into user behavior, network communication, protocol usage, and cloud-service operations.

## Objectives

- Monitor authentication success and failure activity.
- Identify users with high login attempts.
- Analyze network traffic by protocol.
- Monitor communication between source and destination systems.
- Identify unusual ports and protocol activity.
- Analyze cloud service traffic and operations.
- Visualize authentication methods and traffic trends.
