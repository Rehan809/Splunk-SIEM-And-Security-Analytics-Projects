
# DHCP Traffic Insights — Log Monitoring & Dashboard

This project focuses on analyzing DHCP (Dynamic Host Configuration Protocol) logs using Splunk Enterprise SIEM.
DHCP logs provide visibility into how devices obtain IP addresses and communicate within a network. By ingesting DHCP logs into Splunk, this project demonstrates how network administrators and SOC analysts can monitor IP assignments, identify active clients, and understand DHCP request patterns.

## Objectives

- Ingest DHCP log data into Splunk.
- Analyze DHCP requests and lease information.
- Monitor client IP and MAC address assignments.
- Identify frequently active network clients.
- Track DHCP request trends over time.
- Develop a centralized DHCP monitoring dashboard.
